# Lessons Learned

## AI Usage

At the beginning of the project, I was completely ignorant to web design. I still am, but I am learning. My mistake before was to get AI to fill in this lack of competency. However, I now realize that AI creating the project defeats the entire purpose. Despite the fact that I was heavily involved in the entire design process and every button, I didn't write any code. I didn't have a Github Repo. However, I now have learned that these systems are necessary, and will implement. I will still use AI, and here is how:

- Teaching Unfamiliar Coding Concepts
- Brainstorming Designs
  -All code in the website will be human written. However, agentic coding tools are extremely powerful. These can be used to get ideas straight into prototypes. Once the prototype is at a good quality, then I will code based off of the prototype.
- Research and Finding Sources
- Acting as a Project Mentor

I believe that these are ethical ways to use AI. I am learning a lot, and that is the exciting part!
