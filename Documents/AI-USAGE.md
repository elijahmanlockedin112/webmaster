# AI Usage

Below are some ways that I believe AI can be used ethically in this project.

1. Teaching Unfamiliar Coding Concepts
2. Brainstorming Designs/Prototyping
  - All code in the website will be human written. However, agentic coding tools are extremely powerful. These can be used to get ideas straight into prototypes. Once the prototype is at a good quality, then I will code based off of the prototype.
  - [Prototype Repo](https://github.com/elijahmanlockedin112/academy-prototype)
3. Research and Finding Sources
4. Acting as a Project Mentor (Best Practices, Github, Accessibility, etc.)
5. Updates Changelog/Documents
6. Development of Certain Assets, Such as Images
   - The vast majority of assets will be human made. However, with strict scrutiny, AI may be used to develop assets that otherwise would require copyrighted works, such as certain images.
